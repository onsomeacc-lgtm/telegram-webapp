# Telegram Mini App — интерактивная история

Прототип Telegram Web App с механикой:

1. Белый вступительный экран с двумя титрами.
2. Тап запускает звук и переход в историю.
3. Три полноэкранные сцены в формате stories со свайпом влево.
4. Тап по каждой сцене даёт визуальную реакцию, haptic/vibration и короткий звук.
5. После третьей сцены открывается общая галерея из 15 изображений.

## Структура

- `index.html` — разметка приложения.
- `style.css` — визуальная система и адаптивная верстка.
- `app.js` — навигация, свайпы, haptic и звук.
- `assets/story-01.svg` ... `story-03.svg` — изображения сцен-заглушки.
- `assets/photo-01.svg` ... `photo-15.svg` — изображения галереи-заглушки.

SVG-заглушки можно заменить на реальные JPG/WebP, сохранив имена файлов.

## Запуск

Приложению нужен HTTPS-хостинг для запуска внутри Telegram. Разместите содержимое репозитория на статическом хостинге и укажите URL в настройках Mini App через `@BotFather`.

Для локального просмотра:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080` в браузере.

## Telegram

Приложение подключает официальный `telegram-web-app.js`, вызывает `ready()` и `expand()`, а для интерактивных тапов использует `HapticFeedback` с fallback на `navigator.vibrate`.
