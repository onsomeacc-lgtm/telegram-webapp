# Telegram Web App — интерактивные 3 сцены

Открывает 3 полноэкранные сцены, переключаемые вертикальным свайпом.
Тап по сцене даёт haptic/vibration и короткий звук.
После свайпа вверх с третьей сцены открывается галерея.

## Как заменить фотографии галереи
В `index.html` замените блоки `.tile empty` на:
`<div class="tile"><img src="gallery/01.jpg"></div>`
и положите фотографии в папку `gallery/`.

## Запуск
Нужен HTTPS-хостинг для Telegram Web App. После размещения `index.html` URL можно указать боту как Web App URL.
